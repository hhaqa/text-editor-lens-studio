# Lens Studio - text project + PSD file


## Simple Tap Game

A basic example game for Lens Studio is available in `text-edit/Public/Scripts/SimpleTapGame.js`.

1. Add a `SceneObject` for the target with an `InteractionComponent` and `ScreenTransform`.
2. Create a `Text` component to display the score.
3. Attach `SimpleTapGame.js` to a script component and assign the target and score text in the Inspector.

Tapping the target will move it to a random position and increase the score displayed.
